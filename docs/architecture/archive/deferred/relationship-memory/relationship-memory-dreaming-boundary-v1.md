# Relationship Memory Dreaming Boundary v1

- Status: Preparation-only interpretation of ADR-017; not Dreaming authorization
- Scope: REL-MEM-06

Any future Relationship Memory Dreaming process is Area-local, offline, and
snapshot-bound. It may only create inactive, non-retrievable candidates for
duplicate, conflict, staleness, bounded-enrichment, or relevance hypotheses.
It cannot perform cross-scope linking, activation, promotion, active-memory
mutation, policy/approval change, tool invocation, external effects, goal or
plan generation, or Dreaming runtime execution. Unknown guard, lease, snapshot,
scope, provenance, classification, retention, or review state denies the run.
