# S1-06.2 Memory Authority Resolver Traceability

## Scope

S1-06.2 supplies a bounded Protected Control Plane resolver for the retained
Memory Core subsystem. It resolves a trusted issuer, exact catalogued grant
identifiers, and trusted runtime request into one deterministic, immutable
authority snapshot. It does not call a Memory Transition Gate, enable MS-2
retrieval or promotion, create a Goal or Action runtime, or cause an external
effect.

## Normative sources and invariants

| Source | Requirement | Repository evidence |
| --- | --- | --- |
| ADR-018 | Cognitive capability never creates authority; protected state and effects remain Gate-owned. | Resolver has no Gate, database-write, tool, or effect dependency. |
| ADR-019 | Runtime context can only narrow immutable authenticated Tenant identity; payload cannot select scope. | `TrustedMemoryAuthorityContext`; `derive_memory_authority_context`; deny tests. |
| Architecture Directive v4.0 | Unknown identity, scope, lineage, authority, or policy denies by default. | `MemoryAuthorityResolver.resolve` and unit tests. |
| Retained ADR-015 Memory Core controls | Memory Gate is the sole protected-memory writer. | Resolver returns evidence only; contract boundary remains unreleased. |

## Requirement-to-test mapping

| Requirement | Tests | Expected outcome |
| --- | --- | --- |
| Deterministic canonical immutable snapshot | `tests/unit/test_memory_authority.py::test_resolver_is_deterministic_and_snapshot_digests_are_canonical_and_immutable` | Same authenticated inputs and clock produce identical, digest-bound evidence; tampering is rejected. |
| Unknown, mismatched issuer, revoked, expired, or scope-mismatched authority denies | `tests/unit/test_memory_authority.py::test_resolver_denies_unknown_issuer_or_scope_mismatched_context`; `test_unknown_revoked_expired_or_widened_request_is_denied` | No snapshot is returned. |
| A derived context only preserves or narrows grants and scope | `tests/unit/test_memory_authority.py::test_derived_context_can_only_reduce_grants_and_preserve_authenticated_scope` | Scope or grant widening is rejected before resolution. |
| Persistence never fabricates digests for existing evidence | `tests/migrations/test_memory_authority_snapshot_digests.py` | Upgrade stops for unexpected legacy rows pending audited reconciliation. |

## Deliberate non-claims

This task is foundation security evidence only. It does not claim a released
authority administration workflow, revocation propagation service, Gate
integration, retrieval, disclosure, promotion, Goal, Action, execution,
external effects, or recognition maturity.
