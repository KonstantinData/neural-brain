# S1-06.3 Memory Snapshot and Policy Evidence Traceability

## Scope

S1-06.3 validates a pre-transition Memory Core evidence bundle. It re-resolves
current catalogued authority and binds the immutable authority snapshot to an
exact current policy decision, trusted checkpoint identifier, policy-activation
four-eyes evidence when the decision requires it, and the existing `audit`
obligation. The validator is not a Memory Transition Gate and cannot write
memory, commit audit evidence, grant authority, or enable a later Memory Core
operation.

## Normative sources and invariants

| Source | Requirement | Repository evidence |
| --- | --- | --- |
| ADR-018 and Architecture Directive v4.0 | Cognitive capability cannot create authority; unknown or stale authority, scope, policy, or approval denies. | `validate_memory_request_evidence` re-resolves the authenticated context and rejects mismatched policy, scope, expiry, revocation, and approval evidence. |
| ADR-019 | Runtime scope only narrows authenticated database-bound identity. | Trusted request and resolver context are compared through a newly resolved snapshot; payload is not an input. |
| Retained ADR-015 Memory Core controls | Memory Gate is the sole writer and commits audit atomically. | The validator requires the accepted `audit` obligation but never claims audit completion or calls a Gate. |
| Existing policy activation contract | Policy activation requires independent four-eyes evidence. | `IndependentPolicyApproval` is accepted only when the decision requires its exact policy digest and role. |

## Requirement-to-test mapping

| Requirement | Tests | Expected outcome |
| --- | --- | --- |
| Exact current authority, policy, approval, checkpoint, and audit-obligation binding | `tests/unit/test_memory_request_evidence.py::test_current_snapshot_policy_approval_and_audit_obligation_bind_exact_request` | The bounded evidence check succeeds without a transition. |
| Scope, expiry, audit obligation, approval role, and future-approval failures deny | `tests/unit/test_memory_request_evidence.py::test_scope_policy_approval_and_audit_mismatch_deny` | No admissible pre-transition evidence result is produced. |
| Revoked or expired grant invalidates a captured snapshot | `tests/unit/test_memory_request_evidence.py::test_revoked_or_expired_current_grant_invalidates_captured_snapshot` | Re-resolution fails closed. |
| Snapshot or policy digest substitution denies | `tests/unit/test_memory_request_evidence.py::test_snapshot_or_policy_binding_digest_substitution_is_denied` | A decision cannot be reused for a different authority evidence record. |

## Deliberate non-claims

There is no Memory Transition Gate integration, transition-approval contract,
audit-event persistence binding, retrieval, disclosure, promotion, Goal or
Action runtime, execution, or external effect. A later Gate task must bind the
validated preflight evidence and its atomic audit record in one transaction.
