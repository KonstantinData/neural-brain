- Status: Foundation reconciliation evidence
- Task: S1-03.3

  ADR-019, Architecture Directive v4.0
- Delivery stage: NB-0 / MS-1 foundation only

## Scope and non-claims

This record reconciles the residual S1-03.3 acceptance criterion with the
immutable migration plan established by PR #6 and extended through `0011`.
It adds no schema, writer, lifecycle transition, recovery operation, Goal,
Action, external-effect, or capability-release surface.

ADR-018 and Directive v4.0 define the complete target system, while ADR-015
retains authority only for the Memory Core subsystem. The complete target does
not authorize an early protected Goal or Action runtime: those capabilities
remain staged until NB-5. The MS-1 schema therefore remains scoped to Memory
Core observations, bounded working context, checkpoints, inactive candidates,
idempotent transition receipts, audit evidence, and guarded recovery readback.

## Verification boundary

The repository contains executable static and live PostgreSQL evidence for the
implemented MS-1 subset. Live database tests and migration validation require
`MIGRATION_ADMIN_DSN`; an unavailable local DSN is a skipped local check, not
completion evidence. Required CI supplies the disposable PostgreSQL 18 service.

The mapping deliberately does not treat MS-2 registered sources, episodic or
semantic records, retrieval, retention/deletion execution, or MS-3 promotion
and rollback as implemented. Those later lifecycle controls remain separate
backlog work and cannot be substituted by this reconciliation record.
