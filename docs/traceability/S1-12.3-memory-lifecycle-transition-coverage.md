## Scope and non-claims

This record completes the transition-test inventory for the protected Memory
Core that exists in the repository at delivery time.  It does not implement a
new lifecycle state, writer, database function, model, retrieval surface,
Dreaming worker, promotion path, or external effect.

ADR-018 keeps the Memory Core as a protected subsystem; it is not the Neural
Brain product boundary.  The Memory Transition Gate is the sole writer: the
only implemented protected mutation is the
atomic MS-1 observation, working-context version, checkpoint, transition
receipt, and audit event committed by `memory_gate.commit_memory_cycle`.
Reads are authenticated, scope-filtered observations of that committed state,
not lifecycle mutations.  `MemoryService.run_dreaming_dry_run` and the direct
PostgreSQL adapter reject before any connection or persistent-state action.

`N/A` below is a current-maturity status, not a successful implementation
claim.  It means that no transition is enabled and that a later-stage runtime
must carry its own transition, authority, audit, recovery, and evaluation
evidence before this inventory can change.
