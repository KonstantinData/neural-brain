# S1-13.5: Protected Ledger Backup, WAL PITR, and Restore Evidence

- Task ID: `S1-13.5`
- Objective: product-neutral, fail-closed requirements for PostgreSQL ledger
  backup, continuous WAL point-in-time recovery, retention, access separation,
  and independent restore evidence.
- Delivery stage: NB-0 Foundation operational control; it does not advance an
  NB capability stage.
- Governing sources: ADR-003, ADR-018, ADR-019, Architecture Directive v4.0,
  Recognition Standard, and `ledger-invariants.json`.

## Acceptance mapping

| Acceptance criterion | Versioned evidence |
| --- | --- |
| Backup, WAL/PITR, RPO/RTO, retention, encryption, and restore controls are bounded. | `docs/architecture/contracts/protected-ledger-backup-recovery-v1.json` |
| Backup, key, restore, witness, runtime, and recovery-decision duties remain separated. | Contract `access_separation`; `docs/runbooks/protected-ledger-backup-recovery.md` |
| Recovery preserves Gate-only writer, scope, audit, reconciliation, and `indeterminate` semantics. | Contract `invariants`, `restore_acceptance`, and `fail_closed_semantics` |
| Missing environment evidence is a release stop, not a deployment claim. | Contract `current_state`, `non_claims`, and `release_stop_conditions` |
| Static contract shape and non-claim boundary are deterministic. | `tests/architecture/test_protected_ledger_backup_recovery_contract.py` |

## Scope and non-claims

This task adds no migration, backup target, archive, scheduler, encryption key,
credential, retention value, RPO/RTO target, restore environment, production
operation, or restored data. It does not prove encryption, backup completeness,
WAL continuity, restore success, RPO/RTO achievement, or productive readiness.
The task cannot authorize a transition, external effect, runtime identity, or
release. Future deployment evidence remains explicit: approved parameters,
least-privilege/key separation, immutable secret-free operation evidence,
isolated restore test, measured RPO/RTO, independent witness, reconciliation,
and authorized cutover decision.
