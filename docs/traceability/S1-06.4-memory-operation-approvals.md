# S1-06.4 Memory Operation Approval Traceability

## Scope

S1-06.4 introduces an immutable, fail-closed approval-evidence contract for one Memory Core request. It binds authenticated actor, complete scope, checkpoint, operation, exact resource, data class, purpose, environment, authority snapshot, request digest, policy decision, policy digest, approver identity and role, and expiry. It does not implement an approval channel, persist a record, call a Memory Transition Gate, or commit an audit event.

## Normative sources and invariants

| Source | Requirement | Repository evidence |
| --- | --- | --- |
| ADR-018 and Architecture Directive v4.0 | Protected Control Plane evidence cannot create authority; unknown identity, scope, authority, policy, or approval denies. | `MemoryOperationApproval` is strict and immutable; `validate_memory_operation_approval_evidence` checks every exact request and policy fact. |
| ADR-019 | Runtime context may only narrow authenticated identity. | Actor, Tenant, Area, Project, and Session must equal the immutable authority snapshot; payload fields are forbidden. |
| Retained ADR-015 Memory Core controls | The Memory Transition Gate remains the only writer and audit is atomic with transition. | This seam validates evidence only and has no repository, Gate, or audit write dependency. |
| S1-06.3 | Current authority and policy evidence are independently required. | Documentation and implementation explicitly retain S1-06.3 as a separate required validation; an approval has no authority-resolver path. |

## Requirement-to-test mapping

| Requirement | Tests | Expected outcome |
| --- | --- | --- |
| Exact bounded request and policy approval validates as evidence only | `tests/unit/test_memory_operation_approval.py::test_approval_binds_one_memory_operation_without_authorizing_a_transition` | One immutable approval digest is produced; no transition occurs. |
| Scope, actor, operation, resource, purpose, data class, authority, policy, role, expiry, and denied/unrequired policy mismatches fail closed | `tests/unit/test_memory_operation_approval.py::test_scope_actor_operation_resource_purpose_data_policy_role_and_expiry_mismatch_deny` | No admissible approval evidence is produced. |
| Requester cannot self-approve and payload cannot add authority | `tests/unit/test_memory_operation_approval.py::test_actor_cannot_self_approve_and_unknown_payload_fields_are_rejected` | Model construction rejects the evidence. |
| Future or pre-authority approval fails | `tests/unit/test_memory_operation_approval.py::test_future_or_pre_authority_evidence_approval_is_denied` | No admissible approval evidence is produced. |

## Deliberate non-claims

This is neither a Human Gate nor a transition approval. It does not claim an authenticated operator approval channel, approval persistence, approval consumption, single-use semantics, Memory Transition Gate integration, atomic audit persistence, retrieval, disclosure, promotion, deletion, Goal, Action, execution, or external effects.
