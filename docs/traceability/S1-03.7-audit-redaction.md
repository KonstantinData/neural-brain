# S1-03.7: Privacy-Aware Audit Redaction and Evidence References

- Status: implemented MS-1 foundation control
- Task: S1-03.7
- Governing decisions: ADR-003, ADR-018, ADR-019, Architecture Directive v4.0
- Delivery stage: NB-0 / MS-1 foundation only

## Scope and non-claims

This control retains the protected Memory Core audit ledger while preventing a
second durable copy of observation content, credentials, secrets, prompts, or
deletable protected payloads in `memory_audit.events`. It does not implement a
Policy Decision runtime, approval, Goal or Action runtime, external effect,
deletion workflow, or a new protected-state writer.

`memory_gate.commit_memory_cycle` remains the sole implemented Memory
Transition Gate writer. The redaction trigger runs inside that same transaction
before the canonical hash-chain trigger. An audit failure therefore rolls back
the complete protected transition.

## Redacted evidence contract

Migration `0014_memory_audit_redaction.sql` permits only the four currently
implemented Gate event types. An unknown event type fails closed. A recursive
name-based sensitive-field detector rejects raw secret, credential,
authorization, cookie, prompt, content, payload, and token fields before any
audit row is inserted.

For an accepted event the stored `evidence` is replaced with the fixed
`s1-03-7-v1` envelope. Actor and immutable Tenant/Area scope remain the typed
event columns. The envelope records the event decision, committed or provisioned
result, the truthful current policy state (`not_implemented` for MS-1), and
only typed transition-request and subject evidence references. It does not copy
the incoming evidence values.

`memory_gate.read_redacted_memory_audit_event` is an authenticated, scoped
read Gate. It returns typed actor/scope, the redacted envelope, and the
hash-chain evidence for one scoped sequence. It does not provide table DML or
access outside the authenticated Tenant/Area.

  proves normal gate events preserve actor, scope, decision, result, references,
  and a verifiable hash chain without copying observation content.

  proves sensitive payload rejection, no partial audit append, and scoped read

  fail-closed event allowlist, pre-hash redaction, authenticated read Gate, and
  target-stage non-claims.

evidence. CI runs the disposable PostgreSQL 18 suite.
