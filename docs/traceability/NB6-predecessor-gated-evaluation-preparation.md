# NB-6 Predecessor-Gated Evaluation Preparation Traceability

## Objective

Create a fail-closed preparation package for future NB-6 held-out transfer,
causal intervention, calibrated metacognition, and independent G8 reproduction
without implementing, activating, or claiming an NB-6 capability.

## Normative sources

- ADR-018: complete cognitive system and independent Protected Control Plane.
- docs/architecture/architecture-directive-v4.0.md, sections 10-14:
  promotion, metacognition, delivery order, evidence, and release stops.
- docs/architecture/delivery-roadmap.md: NB-5 is the hard predecessor of
  NB-6 and no current stage has complete exit evidence.
- docs/architecture/neural-brain-recognition-standard.md: R1-R10 are
  non-compensatory and recognition does not imply consciousness or autonomy.
- docs/architecture/evaluation-framework.md and
  docs/architecture/contracts/evaluation-gates.json: G5, G6, G8 and frozen
  evaluation requirements.

## Acceptance criteria

- [x] A machine-readable preparation-only NB-6 contract exists.
- [x] The contract makes predecessor, custody, independence, and non-compensatory requirements explicit.
- [x] Tests reject a claim that preparation passes a gate, releases NB-6, or creates authority.
- [ ] NB-6 implementation, evaluation registration, hidden evaluation, G5/G6/G8 passage, and recognition are complete. These are blocked by the external dependencies above.
