## Scope and non-claims

`memory_gate.read_scoped_memory_audit_timeline` is a bounded, authenticated
read Gate for operators and independent verification. It reconstructs currently
implemented Memory Core transition evidence from the redacted, immutable
Tenant/Area audit ledger. It neither writes protected state nor exposes a
general Memory Core query surface.

The function revalidates authenticated read authority and the complete canonical
audit hash chain for immutable Tenant/Area scope. It returns only typed actor,
scope, transition-request, derived-subject references, redacted
decision/result/policy/provenance references, occurrence ordering, and hash
evidence. Cursor and result size are bounded and invalid inputs fail closed.

It does not select `memory_core.observations`, working-context values,
checkpoints, transition request/result documents, candidate payloads, raw
sensitive data, or any table DML. S1-03.7's fixed envelope is the sole source
of evidence fields. The existing MS-1 schema has no implemented deletion,
quarantine, or candidate-lifecycle transition runtime; this read Gate cannot
expose such content and does not claim their implementation or reconciliation.

This is not a Policy Decision, approval, reconciliation runtime, Goal or Action
runtime, external-effect path, lifecycle writer, or recognition/maturity claim.
`memory_gate.commit_memory_cycle` remains the sole implemented Memory
Transition Gate writer.
