- Status: Foundation reconciliation evidence

- Delivery stage: NB-0 / MS-1 foundation only

## Scope and non-claims

This record reconciles the already merged PostgreSQL migration and role-control
implementation with the S1-03.2 acceptance criteria. It introduces no schema,
runtime role, transition, or capability. In particular, it does not enable
Dreaming, retrieval beyond the existing MS-1 read gates, lifecycle promotion,
Goal or Action state, external effects, or a cognitive maturity claim.

The Memory Transition Gate remains the sole writer of protected Memory Core
state. Runtime roles can invoke only the explicitly granted Gate functions;
they cannot obtain DDL authority or direct protected-table mutation authority.
