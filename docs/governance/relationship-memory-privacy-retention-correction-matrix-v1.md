# Relationship Memory Privacy, Retention, Correction, and Prohibited-Profile Matrix v1

- Status: Preparation-only; no real personal-data processing
- Scope: REL-MEM-04 and Position 2

| Category | Future handling condition | Excluded content |
| --- | --- | --- |
| Explicit interaction preference | purpose-, provenance-, and review-bound; expires | inferred preference, personality, affinity, segmentation |
| Explicit correction | successor candidate with preserved lineage and independent review | silent overwrite or use during conflict |
| Stated interaction constraint | minimum permitted signal for declared purpose | special-category, health, religion, politics, employment, credit data |
| Relationship-context observation | approved narrow source and reviewable context only | location, financial, children, criminal, biometric, secret, vulnerability data |

Retention is purpose-specific and expires by default. A future deletion must
propagate to source records, derivatives, summaries, indexes, embeddings,
caches, replicas, and eligible backup handling, with reconciliation before any
readiness claim. Pseudonymization alone is not anonymization. Qualified privacy
review must establish real purpose, lawful basis, transparency, rights,
retention, legal hold, controller/processor allocation, transfers, and owners;
this matrix establishes none of them.
